# Zen 专注模式与后台状态感知 (Zen Mode)

[English Documentation](zen-mode.md)

MixCode Pi 提供 **Zen 专注模式**（`/toggle-zen-mode`），在隐藏顶部 Tab 栏以最大化纵向阅读空间的同时，保持对后台 Agent 运行状态的轻量级感知。

## 界面布局对比

在多 Agent 并行场景下，顶部 Tab 栏会占用垂直行并分散注意力。Zen 模式隐藏 Tab 栏，并将其压缩为极简的顶部状态圆点。

```text
┌─ 常规多标签视图 ─────────────────────────────────────────────────────────┐
│ [Home] [Agent-01*] [Agent-02] [Agent-03]                     Ctrl+T:Jump │
└──────────────────────────────────────────────────────────────────────────┘

┌─ Zen 专注模式 ───────────────────────────────────────────────────────────┐
│ ── ● (运行中) ● (等待输入) [+1] ──────────────────────────────────────── │
│                                                                          │
│ [Chat 对话流视口]                                                        │
│                                                                          │
│ ── [ZEN] ───────────────────────────────────────────────── Agent-01 ──── │
│ > prompt 输入框                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 核心机制

### 1. 后台状态圆点感知 (`zenStatusMarkers`)

当 Tab 栏隐藏后，后台产生重要状态变更的 Agent 会在顶部边框左侧呈现为紧凑的状态圆点：

- **实心圆点 (`●`)**：实时指示后台 Agent 的状态（如正在运行、思考中、等待输入、报错或已完成未读）。
- **溢出折叠计数 (`[+N]`)**：在终端宽度受限时自动折叠超出数量的状态点。
- **鼠标支持**：支持鼠标点击状态圆点直接切换焦点至对应 Agent Tab。

### 2. 状态平滑迁移

Zen 模式具备会话级平滑迁移特性：
- 通过 `Ctrl+T` 跳转至其他 Tab 时，Zen 模式自动迁移到目标 Agent。Zen 下 `Tab` / `Shift+Tab` 被吞掉，不会轮转。
- 切至配置页（`[Home]`）临时展开主页，切回 Agent 后无缝恢复 Zen 视图。

### 3. 编辑器边框角标优先级

编辑器顶部边框按优先级严格排列当前激活的各种交互状态角标：

```text
── [VIM] [ZEN] [INL] ────────────────────────── Agent-01 [sys] ──
```

- `[VIM]`：Vim 对话流浏览模式激活。
- `[ZEN]`：Zen 专注模式激活（Tab 栏已隐藏）。
- `[INL]`：内联挂件模式激活。
- `[sys]`：当前 Tab 设置了自定义 `system_prompt`（跟在标题后面）。

## 命令与操作

| 动作 | 命令 / 快捷键 | 作用说明 |
|---|---|---|
| 切换 Zen 模式 | `/toggle-zen-mode` | 隐藏或恢复顶部 Tab 栏。 |
| 命令面板触发 | `Ctrl+P` → `Toggle Zen Mode` | 在命令面板中搜索触发。 |
| Zen 下 Tab 跳转 | `Ctrl+T` | 在保持 Zen 模式的前提下弹出快速跳转面板。 |
