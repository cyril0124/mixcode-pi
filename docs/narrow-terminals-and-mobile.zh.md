# 窄屏与移动终端优化 (Narrow & Mobile)

[English Documentation](narrow-terminals-and-mobile.md)

MixCode Pi 针对窄屏终端窗口、移动端终端模拟器（如 Termux、iOS Blink/SSH 客户端）及分屏窗格提供专门的自适应降级与触控/鼠标交互优化。

## 1. 窄屏布局自适应与平滑降级

在宽度受限（<80 列）或屏幕高度较小时，MixCode 动态对各类 Chrome 元素执行优雅降级，防止界面布局发生错位截断：

```text
┌─ 极窄 / 移动端布局 (<70 列) ─────────────────────────────────────────────┐
│ H [Agent-01*] [Agent-02]  … +2                                           │
├──────────────────────────────────────────────────────────────────────────┤
│ ── [ZEN] ───────────────────────────────────────────── Agent-01 ── 12k ──│
│ > prompt 输入框                                                          │
├──────────────────────────────────────────────────────────────────────────┤
│ opus-4-5 | /repo/pkg | git                                               │
└──────────────────────────────────────────────────────────────────────────┘
```

### 逐级平滑降级策略

1. **Tab 栏自适应压缩 (`src/ui/rendering/chrome.ts`)**：
   - 宽度受限时 `MixCode Home` 收缩为 `" H "`。
   - 超出视口的 Tab 两端显示 `+N …` / ` … +N`。
   - 激活中的 Tab 标题优先保留完整可读性，非激活 Tab 自动以 `…` 适度截断。
2. **状态元数据行智能压缩 (`compactWorkdir`)**：
   - 长工作区路径自动逐级压缩各级目录（如 `~/w/p/m/packages/cli`）。
   - 模型名称遵循：完整 `provider/modelId` → 简短 `modelId` → 字符截断。
3. **编辑器边框角标丢弃顺序**：
   - 宽度不足时，编辑器顶部角标按非核心优先顺序丢弃：`[INL]` → `[ZEN]` → `[VIM]` → `[sys]`。
4. **挂件高度硬上限保护**：
   - 编辑器上方/下方挂件槽强制执行最大行数上限（超限显示 `… (widgets truncated)`），确保 Chat 视口与输入框永远保留可见的编辑输入空间。

## 2. 移动端触控与鼠标交互支持

手机/平板端 SSH 客户端通过 SGR 1006 协议将屏幕触控转换为鼠标事件：

- **触控点击切 Tab**：轻触 Tab 芯片或窄屏 ` H ` 即可切换。
- **Zen 状态圆点**：只展示状态，不可点。
- **可点击状态栏徽标**：轻触底部状态栏的模型、思考档位或工作目录徽标，直接唤起全屏选择器。
- **滑动划选与边缘自动滚屏**：手指在 Chat 视口中拖拽可精确划选文本，松开后自动提取剥离 ANSI 的纯文本至系统剪贴板。
