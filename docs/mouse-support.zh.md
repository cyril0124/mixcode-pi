# 鼠标交互、点击区域与划选 (Mouse Support)

[English Documentation](mouse-support.md)

MixCode Pi 基于 SGR 1006 扩展协议（`src/ui/app-mouse.ts` 与 `src/core/mouse.ts`）提供全功能终端鼠标交互，支持点击切换 Tab、浮层列表点击、滚动条拖拽以及纯净文本划选复制。

## 1. 可点击区域与命中测试 (Hit Regions)

MixCode 在每帧渲染时精准计算各 UI 元素的矩形命中区域（`MouseHitRegion`），将点击事件直接分发至对应功能：

### 可点击目标清单

| UI 元素 | 点击响应行为 |
|---|---|
| Tab 标签 | 切换到该 Tab。再次点击当前激活的 Tab 标签可打开 Tab Jump 跳转面板。 |
| MixCode Home 标签 | 打开 Home 主页。窄屏下紧凑显示为 ` H `。 |
| Zen 状态圆点 (`●`) | 仅展示后台状态，不支持点击。 |
| 底部 Meta 栏模型徽标 | 打开 `/models` 模型选择器。 |
| 底部 Meta 栏思考档位徽标 | 打开 `/thinking` 深度调整选择器。 |
| 底部 Meta 栏工作目录徽标 | 打开 `/workdir` 文件系统目录选择器。 |
| Chat 滚动条轨道与滑块 | 直接点击跳转或按住滑块拖拽滚动对话视口。 |
| Jump to latest | 将当前聊天移到末尾，并恢复自动跟随。 |

### 回到最新消息

聊天离开末尾或定位到某条消息时，居中的跳转提示浮在原始聊天底行上。左键按下提示后回到末尾，提示消失，后续输出自动跟随。Vim 模式额外显示快捷键 `G`；非 Vim 模式下，`End` 保留编辑器行尾操作。

仅覆盖提示所占的字符区域，左右两侧仍显示原始正文；不预留、不清空、不增加任何行。提示不占滚动条列，按聊天宽度截断，不覆盖图片行。提示文字不进入复制的聊天内容。模态浮层保留输入优先级；鼠标移动、松开、右键和正在进行的文本拖拽不会触发跳转。右侧 widget 面板仍独立滚动。

## 聊天滚动条

主聊天区在普通、Zen 和侧栏布局中，只要内容溢出就持续显示 Pi 风格滚动条。轨道为 `│`，悬停或拖动时滑块从 `┃` 加粗为 `█`。指针离开后恢复细滑块，不自动隐藏。内容未溢出时不显示滚动条。

点击轨道将滑块中心定位到指针处，并在两端限制范围。按住滑块保留抓取位置，拖出轨道后仍可拖动，直到松开。切换 Tab、模态界面接管输入、缩放或终端停止时取消拖动。向上阅读正在生成的回复时，保留原有的新内容箭头。

聊天区为滚动条预留一列，不占用正文或文本选择区域。长会话保留窗口化渲染及总高度估算。第三方 Pi 主题使用 `scrollbarTrack` 与 `scrollbarThumb`；内置 MixCode 主题使用 muted 和 text 前景色。滚动条交互状态由 `src/ui/chat-scrollbar.ts` 管理，几何计算及单元格绘制复用 `pi-tui` 补丁公开的 Pi helper。

`src/ui/terminal.ts` 启用全鼠标移动跟踪 `1003` 与 SGR 坐标 `1006`，并在停止或排空输入时关闭。聊天轨道之外的无按键指针移动不会触发 MixCode 重绘，也不会影响键盘组合键。侧栏仍独立滚动。

## 2. 交互式浮层点击与滚动

全屏选择浮层均支持鼠标操作：

- **命令面板 (`Ctrl+P`)**：点击命令行即执行该命令。
- **Tab 跳转面板 (`Ctrl+T`)**：鼠标点击任意行直接切换至目标会话。
- **模型/工作目录选择器**：鼠标左键点击选定项目，滚轮上下浏览长列表。

## 3. 鼠标滚轮支持

- **对话视口**：滚轮上下滚动聊天历史。
- **侧边栏**：光标悬停在右侧扩展侧边栏上方时，滚轮独立滚动该分栏内容。

## 4. 鼠标文本拖拽划选与自动复制

在 Chat 对话视口、输入框或 Notice 对话框中按住左键拖拽可划选文本：
- **松开自动复制**：松开鼠标左键时，划选内容自动提取并写入系统剪贴板。
- **剥离 ANSI 样式**：自动清除背景高亮与语法着色控制符，输出干净的纯文本。
- **宽字符 (CJK) 边界适配**：`src/core/chat-selection.ts` 将起点列收到 `getGraphemeCellRange(line, col).start`、终点列收到 `.end`，指针下的全宽字不会被切成半格。
- **块背景覆盖**：同一 helper 在选中片段的每段 SGR 之后重打 `theme.selectedBg`，tool/thinking 卡片底色不会盖住划选高亮。
- **边缘自动滚屏**：拖拽至视口上下边缘时，自动触发向上/向下滚动并延续划选范围。
