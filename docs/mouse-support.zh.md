# 鼠标交互、点击区域与划选 (Mouse Support)

[English Documentation](mouse-support.md)

MixCode Pi 基于 SGR 1006 扩展协议（`src/ui/app-mouse.ts` 与 `src/core/mouse.ts`）提供全功能终端鼠标交互，支持点击切换 Tab、浮层列表点击、滚动条拖拽以及纯净文本划选复制。

## 1. 可点击区域与命中测试 (Hit Regions)

MixCode 在每帧渲染时精准计算各 UI 元素的矩形命中区域（`MouseHitRegion`），将点击事件直接分发至对应功能：

### 可点击目标清单

| UI 元素 | 点击响应行为 |
|---|---|
| Tab 芯片 | 切换到该 Tab。再点一次当前芯片打开 Tab Jump。 |
| MixCode Home 芯片 | 打开 Config/Home。窄屏为 ` H `。 |
| Zen 状态圆点 (`●`) | 只显示状态，不可点击。 |
| 底部 Meta 栏模型徽标 | 打开 `/models` 模型选择器。 |
| 底部 Meta 栏思考档位徽标 | 打开 `/thinking` 深度调整选择器。 |
| 底部 Meta 栏工作目录徽标 | 打开 `/workdir` 文件系统目录选择器。 |
| Chat 滚动条轨道与滑块 | 直接点击跳转或按住滑块拖拽滚动对话视口。 |

## 2. 交互式浮层点击与滚动

全屏选择浮层均支持鼠标操作：

- **命令面板 (`Ctrl+P`)**：点击命令行即执行该命令。
- **Tab 跳转面板 (`Ctrl+T`)**：鼠标点击任意行直接切换至目标会话。
- **模型/工作目录选择器**：鼠标左键点击选定项目，滚轮上下浏览长列表。

## 3. 鼠标滚轮支持

- **对话视口**：滚轮上下滚动聊天历史。
- **Markdown 预览与侧边栏**：光标悬停在右侧扩展侧边栏或 Markdown 预览浮层上方时，滚轮独立滚动该分栏内容。

## 4. 鼠标文本拖拽划选与自动复制

在 Chat 对话视口、输入框或 Notice 对话框中按住左键拖拽可划选文本：
- **松开自动复制**：松开鼠标左键时，划选内容自动提取并写入系统剪贴板。
- **剥离 ANSI 样式**：自动清除背景高亮与语法着色控制符，输出干净的纯文本。
- **宽字符 (CJK) 边界适配**：精准适配双字节东亚字符宽度，避免字符截断裂缝。
- **边缘自动滚屏**：拖拽至视口上下边缘时，自动触发向上/向下滚动并延续划选范围。
