# 内联组件模式 (`[INL]`)

[English Documentation](inline-widgets.md)

MixCode Pi 提供 **内联组件模式 (Inline Widgets Mode)**（`/toggle-inline-widgets`），允许将固定在编辑器周边的扩展组件（Widget）移入可滚动的 Chat 对话流尾部。

## 概念与布局对比

默认情况下，扩展组件（如目标追踪条、定时循环计数器）固定停靠在编辑器输入框的上方或下方。当组件高度较大时，会挤压多行代码编写的垂直视口空间。

内联组件模式将扩展组件渲染移至消息流尾部：

```text
┌─ 默认固定停靠视图 ───────────────────────────────────────────────────────┐
│ [Chat 对话流视口]                                                        │
│                                                                          │
│ ┌ 编辑器上方组件停靠区 ────────────────────────────────────────────────┐ │
│ │ Goal (active) | 3 tasks remaining | tokens: 12.4k                    │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│ ── Agent-01 ──────────────────────────────────────────────────────────── │
│ > prompt 输入框                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ 内联组件视图 (`/toggle-inline-widgets`) ────────────────────────────────┐
│ [Chat 对话流视口]                                                        │
│                                                                          │
│ ▸ Inline · Goal (active) ─────────────────────────────────────────────── │
│ 3 tasks remaining | tokens: 12.4k                                         │
│                                                                          │
│ ▸ Inline · Goal (active) ───────────────────────────────── Agent-01 ──── │
│ > prompt 输入框 (获得完整垂直高度)                                       │
└──────────────────────────────────────────────────────────────────────────┘
```

## 核心行为与规则

1. **自然跟随滚动**：
   - 组件渲染在最后一条消息之后、排队中的 Steer/Follow-up 队列之前。
   - 向上翻页或在 Vim 模式下浏览历史记录时，内联组件随内容自然滚出视口。
2. **内联组件标题 (`▸ Inline`)**：
   - 每个内联组件左上角显示 `▸ Inline · <key>` 标题。
   - 编辑器顶部不再显示内联模式角标；`[VIM]`、`[ZEN]` 和 `[sys]` 保持原有作用。
3. **会话级与全局配置**：
   - **单 Tab 切换**：运行 `/toggle-inline-widgets` 仅切换当前 Tab。
   - **全局默认**：在 `mixcode_settings.json` 中配置 `"ui.inlineWidgets": true`，或在 `/settings` 中勾选 “Inline widgets”。
4. **侧边栏共存策略**：
   - 当右侧扩展侧边栏展开时（空输入框按 `Right`），内联组件自动适配分栏布局。

## 组件显示与 slash command

内联组件默认展开。标题和第一行内容共用一行，以减少垂直空间占用。折叠后只显示标题和一行摘要；展开内容最多显示 20 行。

使用以下 slash command 控制当前 Tab：

| 命令 | 作用 |
|---|---|
| `/widgets` | 在折叠和展开全部组件之间切换 |
| `/widgets expand [key]` | 展开全部组件，或展开指定 key 的组件 |
| `/widgets collapse [key]` | 折叠全部组件，或折叠指定 key 的组件 |
| `/widgets toggle [key]` | 切换全部组件，或切换指定 key 的组件 |

折叠状态只保存在当前会话中。固定停靠组件和侧边栏继续使用原来的完整内容显示方式。


| 命令 / 路径 | 作用说明 |
|---|---|
| `/toggle-inline-widgets` | 切换当前 Tab 的内联组件渲染模式。 |
| `/settings` → `Inline widgets` | 配置新创建 Tab 的全局默认行为。 |
