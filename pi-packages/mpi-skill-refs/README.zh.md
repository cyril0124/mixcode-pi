# mpi-skill-refs

[English](README.md)

补全 `$SkillName` 引用，并向模型提供已解析技能的名称、描述、`SKILL.md` 路径和基准目录。聊天和会话历史中的用户消息保持原文。扩展提供文件指引，由模型读取技能文件。

在输入框键入 `$` 查看候选项，或提交 `用 $review 检查这份 diff`。未知名称、常见环境变量、围栏代码块和 shell 模式输入（`!` / `!!`）不展开。

## 投递与持久化

- 空闲时提交的输入通过 `before_agent_start` 附带隐藏的 `skill-refs` 自定义消息，Pi 将它与用户消息一起持久化。
- Steer 和 follow-up 输入在用户原文送达后，通过 `context` 事件获得技能引用块。这些块只影响模型请求；后续请求和 resume 时，根据已送达的用户消息重新构建。
- 技能元数据不单独占用队列项，也不触发模型轮次。撤回尚未送达的输入后，其中的技能不会进入模型。其他 input handler 消费或改写输入时，只有最终接受的用户原文可以触发展开。
- 上下文中已有的相同引用块会被复用，包括空闲输入产生的持久化块。已有会话条目保持不变。

## 技能发现

`session_start` 扫描项目、用户和已安装包的技能目录，提供补全和初始查询。`before_agent_start` 从 Pi 的 `systemPromptOptions.skills` 刷新权威列表，其中包括扩展提供的技能。列表中缺少的名称回退到扫描结果。

设置 `MIXCODE_PROJECT_SKILLS_ONLY=1`，文件扫描就只读取 `<cwd>/.agents/skills`。未设置、空字符串、`0`、`false`、`off` 和 `no` 均关闭此限制；值会去除首尾空白，且不区分大小写。此设置只影响文件扫描，不修改 Pi 资源加载器提供的技能列表。
