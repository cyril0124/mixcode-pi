# mpi-fzf

[中文](README.zh.md)

Install `fzf` on your `PATH`. In an interactive session, press `Ctrl+P` and choose `/fzf`, or enter `/fzf` in an empty editor. Inside the picker, press Alt+Up to search the parent directory. Press it again to move up another level. Press Enter to insert the selected path relative to the current working directory at the cursor. Press Esc to keep the draft as it is.
