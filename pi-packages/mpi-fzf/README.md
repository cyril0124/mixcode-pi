# mpi-fzf

[中文](README.zh.md)

Install `fzf` on your `PATH`. In an interactive session, press `Ctrl+P` and choose `/fzf`, or enter `/fzf` in an empty editor. Search for a file under the current working directory and press Enter to append its relative path to the draft exactly as shown, including spaces. Press Esc to keep the draft as it is.
