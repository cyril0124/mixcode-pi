# mpi-cron

[English](README.md)

在任意 MixCode tab 中安排定时提示。任务属于工作目录而不是某个 session，因此由其他 tab 创建、由 subagent 创建，或重启前创建的任务都会继续触发。widget 显示本 tab 自己创建的任务，以及由 subagent 创建的任务；`/cron` 会列出本目录的全部任务。


## 入口

| 入口 | 用途 |
|---|---|
| `cron` 工具 | agent 创建、列出、更新、删除、启用/停用、立即触发与清理任务。 |
| `/cron` | 管理浮层：可过滤的任务列表（调度、执行次数、距上次执行时间）、内建创建向导、含提示词的任务详情、暂停/恢复、立即触发、删除、清理。 |
| `/cron stop <id\|name>` | 直接按 id 或名称删除任务，无需打开浮层。Tab 补全列出当前所有任务。 |
| Widget | `belowEditor` 常驻组件，显示本 tab 自己创建的任务与 subagent 创建的任务的状态、调度、距下次触发时间与执行次数。没有可显示的任务时隐藏。 |
| 会话标记 | 每次执行结束都会向收到该提示词的 session 追加一条 `scheduled_prompt` 记录，其中包含本次执行结果。 |

widget 与列表共用同一组状态符：`~` 运行中、`!` 上次执行失败、`*` 已启用、`x` 已暂停。

## 调度格式

时间均为本地时间；5 字段表达式表示秒为 0。

| 形式 | 示例 | 说明 |
|---|---|---|
| Cron 5 字段 | `0 9 * * *`、`*/15 * * * *`、`0 9-17 * * MON-FRI` | 支持 `*`、`n`、`n-m`、`n-m/s`、`*/s`、逗号列表、月份与星期名称。日与星期同时受限时按 cron 惯例取“或”。 |
| Cron 6 字段 | `0 */5 * * * *`、`*/10 * * * * *` | 首位为秒字段。 |
| 间隔 | `5m`、`every 2h`、`90s` | 对齐到 epoch 网格：触发时刻是间隔的整数倍，因此重启或其他 tab 不会让触发时间漂移。 |
| 相对时间 | `+30s`、`+5m`、`+2h`、`+1d` | 只触发一次，之后自动停用。 |
| ISO 时间戳 | `2026-09-23T09:00:00Z`、`2026-09-23 09:00` | 未带时区按本地时间处理。只触发一次，之后自动停用。 |

## 任务归属与“恰好一次”认领

```text
tab A ─┐
tab B ─┼─► 模块级 hub（每进程一个）─► 每个启用任务一个 timer
child ─┘         │
                 ▼  触发
     <cwd>/.pi/cron/jobs.json   在独占锁下 claim(id, token)
                 │
        赢家 ────┴──── 输家：token 已写入，跳过本次执行
```

- 存储在 `<cwd>/.pi/cron/jobs.json`，通过 `<jobs.json>.lock` 旁路锁与原子 rename 写入，因此并发 tab 与同目录的其他 `mpi` 进程不会交错读改写。
- 触发时用 token（定时器触发即为计划的触发时刻）认领任务。hub 在投递提示词之前写入认领，因此第二个 tab 或第二个进程会看到 token 并跳过本次执行。当存储中的 `nextRun` 已经越过本次要触发的 tick 时，认领同样会被拒绝，因此对已在其他进程执行过的 tick，过期的计划不会重复投递。
- 崩溃遗留的认领在 30 分钟后可被重新认领；在此之前任务保持已认领状态。因此崩溃只会推迟一次执行，而不会丢弃它。
- 即使当前没有任何存活 session，执行结果仍会写入存储，调度继续推进。

## 投递

- 提示词以 `expandPromptTemplates` 注入，因此任务内容可以包含 `/command`、`$skill` 或 prompt template，与手动输入一致。
- agent 繁忙时提示词作为 follow-up 投递，不会丢失。
- 投递优先选择创建该任务的 session，执行结果回到当初安排它的 tab；否则投给第一个交互 tab。subagent 的 session 不是投递目标，因为它不注册。
- 一次执行只进入一个 session：先由存储认领取胜出进程，再由该进程按上述规则选目标。

## Subagent 会话

`pi-subagents` 以 `<type>#<8 个字符>` 命名子会话。此类 session 可以创建和读取任务，任务写入父目录的存储并显示在交互 tab 的 widget 中，但它不持有 timer，也不持有 widget。

## 工具动作

| 动作 | 必填参数 | 说明 |
|---|---|---|
| `add` | `schedule`、`prompt` | 可选 `name`、`description`。在被触发执行的提示词内部会被拒绝，避免任务自行串联成链。 |
| `list` | 无 | 汇总本目录的全部任务。 |
| `update` | `jobId` | 可改 `name`、`description`、`prompt`、`schedule`、`enabled`。 |
| `remove` | `jobId` | 删除任务。 |
| `enable` / `disable` | `jobId` | 恢复或暂停，不删除。 |
| `fire` | `jobId` | 立即执行；仍然走认领，因此手动触发不会与待执行的一次重复。 |
| `cleanup` | 无 | 删除本目录中已暂停的任务。 |

`jobId` 接受精确 id、唯一名称或唯一 id 前缀。调度已耗尽的任务（一次性任务已执行，或 cron 表达式再也不会命中）会自动停用，而不是无限触发。

## 浮层按键

| 按键 | 行为 |
|---|---|
| `↑` `↓`、`j` `k` | 移动选中项 |
| `Enter` | 打开任务详情；详情内用 `↑`/`↓`、`j`/`k`、`Ctrl+D`/`Ctrl+U`、`g`/`G` 滚动提示词 |
| `n` | 创建任务：先填调度，再填提示词，最后填可选名称 |
| `space` | 暂停或恢复选中任务 |
| `f` | 立即触发选中任务 |
| `d` | 删除选中任务，先按 `y` 确认 |
| `c` | 清理已暂停任务，先按 `y` 确认 |
| 可打印字符 | 过滤；`Ctrl+U` 清空过滤 |
| `q`、`Esc`、`Ctrl+C` | 关闭（详情内 `Esc` 返回列表） |

创建向导内，`Enter` 确认当前字段，`Esc` 返回上一个字段。
