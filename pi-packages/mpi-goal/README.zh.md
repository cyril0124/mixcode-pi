# mpi-goal

[English Documentation](README.md)

MixCode 内置的会话级自主目标追踪扩展。

## 功能概述

`mpi-goal` 提供会话级隔离的自主目标追踪引擎，支持渐进式动态工具暴露、执行预算控制与多目标排队调度。

## 命令与用法

| 命令 | 作用 |
|---|---|
| `/goal` | 打开交互式目标管理浮层面板 |
| `/goal <objective>` | 创建、替换或排队新目标 |
| `/goal tools` | 为当前会话显式激活 Goal 模型工具 |
| `/goal pause` / `resume` / `clear` | 控制目标生命周期（暂停/恢复/清除） |
| `/goal queue …` | 列出或添加目标排队项 |

- **会话级隔离**：状态存储于当前会话分支的 `mpi-goal-state` 条目中，多 Tab 互不干扰。
- **渐进式动态工具暴露**：目标工具默认不注入上下文，仅在激活时挂载。
- **活跃时间统计**：仅统计 Agent 在实际运行轮次中的耗时（排除空闲与暂停）。
