# Loop UI 手动演示

[English](README.md)

在 `loop-ui` worktree 根目录运行：

```bash
./tmp/loop-ui-manual/run.sh
```

启动后给扩展加载预留约 5 秒，在 Home 选中 `Agent-01`，按右方向键进入会话。建议先使用约 120 列、40 行的终端。

该演示使用本地离线的 `loop-ui-demo/alpha` 模型，界面中显示为 `Loop UI Offline`。配置和会话保存在临时目录，退出时自动删除。建议使用 120 列、40 行的终端。Home 页面等待约 5 秒扩展加载完成后，在 `Agent-01` 上按右方向键进入会话。

## 观察定时调度

1. 输入 `/loop 10s --max-runs 3 checkpoint`。底部出现 `Loops (1)` 和 `1/3`。
2. 等待 10 秒。首个本地模型响应故意延迟 25 秒，因此真实定时器会把挂件状态改成黄色 `waiting`，次数仍为 `1/3`。
3. 约第 31 秒出现 `Local reply 3`。任务达到总次数上限，挂件消失。

## 检查布局与交互

1. 输入 `/loop`。每个任务占两行。按下方向键选中 `#3`，再按上方向键和 Enter 查看 `#2`。
2. 按 `G` 到 `END-CHECKLIST`，按 `g` 返回 `DEPLOY-CHECK`。将终端依次缩为 60 列、40 列，保持 28 行；每次等画面重绘后再按 `G`，末行和 `q close` 都应可见。然后恢复宽窗口。
3. 按 `g` 后按 `c`，输入 `0` 并回车。看到 `Error: Max runs`，原上限保持不变。按 Escape 取消输入；重新按 `c`，输入 `5` 并回车，详情显示 `Runs: 1/5`。按 `m` 显示 `When busy: skip`，再按一次恢复 `defer`。
4. 按 `x`，删除确认出现在底部，Prompt 仍可见。按 `q` 取消确认，详情页保持打开。按左方向键返回列表，看到 `Search: _` 后输入 `deploy`，列表只保留 `#2`；按 Ctrl+U 恢复两个任务。
5. 在列表按 `c`，底部出现 `Remove all 2 loops?`，任务列表仍然可见。按 `q` 取消；再次按 `c` 后按 `y` 确认清空，出现 `No matching loops`。

按 `q` 关闭管理页，再输入 `/quit`。演示退出并删除临时运行目录。再次运行启动脚本会得到新会话，任务 ID 从 `1` 开始。
